# Database Schema - Ticketing System

## Table: ticket

```sql
create table public.ticket (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  ticket_id text null,
  subject text null,
  category bigint null,
  status bigint null,
  assigned_to bigint null,
  constraint ticket_pkey primary key (id),
  constraint ticket_assigned_to_fkey foreign KEY (assigned_to) references kasubag (id),
  constraint ticket_category_fkey foreign KEY (category) references "Category_divisi" (id),
  constraint ticket_status_fkey foreign KEY (status) references "Status_ticket" (id)
) TABLESPACE pg_default;
```

## Auto-Generate Ticket ID Trigger

```sql
create trigger ticket_id_before_insert 
BEFORE INSERT on ticket 
for EACH row
execute FUNCTION generate_ticket_id();
```

## Related Tables

### 1. Category_divisi
- `id` (bigint, primary key)
- `nama_divisi` (text) - Category name

### 2. Status_ticket
- `id` (bigint, primary key)
- `nama_status` (text) - Status name (e.g., Open, In Progress, Resolved, Closed)

### 3. kasubag
- `id` (bigint, primary key)
- `nama_kasubag` (text) - Assignee name

## CRUD Operations

### Create Ticket
- Ticket ID is auto-generated by database trigger
- Required fields: subject, category, status, assigned_to
- Created timestamp is auto-generated

### Read Tickets
- Fetches all tickets with JOIN to related tables
- Search by subject or ticket_id
- Ordered by created_at (newest first)

### Update Ticket
- Can update: subject, category, status, assigned_to
- Cannot update: id, created_at, ticket_id

### Delete Ticket
- Permanent deletion with confirmation dialog
- Cascading deletes handled by database constraints

## Usage in Code

```javascript
import { supabase } from "./supabaseClient";

// Fetch tickets with relations
const { data, error } = await supabase
  .from("ticket")
  .select(`
    *,
    category:Category_divisi(id, nama_divisi),
    status:Status_ticket(id, nama_status),
    assigned_to:kasubag(id, nama_kasubag)
  `)
  .order("created_at", { ascending: false });

// Create ticket (ticket_id auto-generated)
const { data, error } = await supabase
  .from("ticket")
  .insert([{
    subject: "Issue title",
    category: 1,
    status: 1,
    assigned_to: 1
  }])
  .select();

// Update ticket
const { error } = await supabase
  .from("ticket")
  .update({ status: 2 })
  .eq("id", ticketId);

// Delete ticket
const { error } = await supabase
  .from("ticket")
  .delete()
  .eq("id", ticketId);
```

## Notes

1. Make sure all related tables (Category_divisi, Status_ticket, kasubag) have data before creating tickets
2. The `generate_ticket_id()` function must be created in Supabase before using the trigger
3. Foreign key constraints ensure data integrity
