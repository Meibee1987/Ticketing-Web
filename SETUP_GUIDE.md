### Step 2: Create Ticket ID Generator Function

```sql
CREATE OR REPLACE FUNCTION generate_ticket_id()
RETURNS TRIGGER AS $$
DECLARE
  new_id TEXT;
  prefix TEXT := 'TKT-';
  counter INTEGER;
BEGIN
  -- Get the latest ticket number
  SELECT COALESCE(MAX(CAST(SUBSTRING(ticket_id FROM 5) AS INTEGER)), 1000) + 1
  INTO counter
  FROM ticket
  WHERE ticket_id LIKE 'TKT-%';
  
  -- Generate new ticket ID
  new_id := prefix || counter;
  
  -- Assign to NEW record
  NEW.ticket_id := new_id;
  
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```

### Step 3: Create Ticket Table with Trigger

```sql
CREATE TABLE public.ticket (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
  ticket_id TEXT NULL,
  subject TEXT NULL,
  category BIGINT NULL,
  status BIGINT NULL,
  assigned_to BIGINT NULL,
  CONSTRAINT ticket_pkey PRIMARY KEY (id),
  CONSTRAINT ticket_assigned_to_fkey FOREIGN KEY (assigned_to) 
    REFERENCES kasubag (id) ON DELETE SET NULL,
  CONSTRAINT ticket_category_fkey FOREIGN KEY (category) 
    REFERENCES Category_divisi (id) ON DELETE SET NULL,
  CONSTRAINT ticket_status_fkey FOREIGN KEY (status) 
    REFERENCES Status_ticket (id) ON DELETE SET NULL
);

-- Create trigger
CREATE TRIGGER ticket_id_before_insert 
BEFORE INSERT ON ticket 
FOR EACH ROW
EXECUTE FUNCTION generate_ticket_id();
```

## Frontend Setup

### Step 1: Clone & Install

```bash
cd d:\Ticketing\ticketing-web
npm install
```

### Step 2: Configure Environment

Create `.env` file:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here
```

Get these values from: Supabase Dashboard → Settings → API

### Step 3: Run Development Server

```bash
npm run dev
```

Visit `http://localhost:5173`

## Testing CRUD Operations

### Create Ticket
1. Navigate to "My Tickets" page
2. Click "New Ticket" button
3. Fill in: Subject, Category, Status, Assigned To
4. Click "Create"
5. Ticket ID will be auto-generated (e.g., TKT-1001)

### View Ticket
- Click 👁️ icon on any ticket row
- Modal opens in read-only mode

### Edit Ticket
- Click ✏️ icon on any ticket row
- Modal opens with editable fields
- Update and click "Update"

### Delete Ticket
- Click 🗑️ icon on any ticket row
- Confirm deletion dialog
- Ticket permanently removed

### Search Tickets
- Use search bar to filter by Subject or Ticket ID
- Real-time filtering

## Troubleshooting

### Error: "Could not find a relationship..."
- Check foreign key names in Supabase
- Ensure related tables exist with data

### Error: "ticket_id is null"
- Check if trigger was created successfully
- Verify function `generate_ticket_id()` exists

### Connection Error
- Verify `.env` file exists and has correct values
- Check Supabase project is active
- Test connection in Supabase Dashboard

## Security Notes

1. **Never commit `.env` file** to Git
2. Use Row Level Security (RLS) in Supabase for production
3. Anon key is safe for client-side, but enable RLS policies
4. For authentication, integrate Supabase Auth
